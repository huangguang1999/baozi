隐私政策

最后更新：2026年3月23日

概述

包子（下称"我们""我们的"或"本应用"）是一款连接到你自己掌控的 Codex 服务器的移动客户端。我们致力于保护你的隐私。本政策说明本应用会处理哪些数据、以及如何处理。

我们不收集的数据

包子不会向我们的服务器收集、存储或传输你的个人数据。具体来说：

  • 我们不收集任何分析或使用埋点数据。
  • 我们不追踪你的位置。
  • 我们不访问你的通讯录、照片或其他设备数据。
  • 我们不向任何第三方出售或共享任何数据。
  • 我们不使用广告 SDK 或追踪像素。

仅保存在你设备上的数据

以下数据仅本地存储在你的设备上，不会传输给我们：

  • 服务器凭据：SSH 密钥、鉴权 token、服务器连接信息，存放在你设备的安全存储中（iOS 钥匙串 / Android EncryptedSharedPreferences）。
  • 应用偏好：主题、字号及其他设置仅本地存储。
  • 已发现的服务器：网络发现结果只保存在内存中，应用会话结束后不再保留。

网络通信

包子直接与你配置的 Codex 服务器通信。通信方式包括：

  • 对于局域网内发现的服务器，走你的本地网络（LAN / Wi-Fi）。
  • 对于远程服务器连接，走 SSH 隧道。
  • 对于通过 Tailscale 发现的服务器，走 Tailscale。

所有对话内容、代码和会话数据都在你的设备和你的 Codex 服务器之间直接流转。我们不代理、不检查、也不存储这些流量。

推送通知

如果你开启推送通知，设备 token 会注册到我们的推送中转服务。该 token 仅用于投递通知，不与任何个人信息关联。你可以随时在设备设置中关闭通知。

语音输入

当你使用语音输入时，音频会被处理用于转写。音频数据直接流式传输到你的 Codex 服务器做实时处理。我们不存储、也不访问你的录音。

第三方服务

包子不集成任何第三方分析、广告或追踪服务。唯一的外部服务通信，是与你明确配置的 Codex 服务器、以及我们的推送中转服务之间的通信。

儿童隐私

包子不面向 13 周岁以下的儿童。我们不会在知情的情况下收集儿童的个人信息。

数据删除

由于我们不收集你的数据，我们的服务器上也没有什么可删除的。要删除全部本地数据，只需从设备上卸载本应用，所有本地保存的凭据和偏好都会随之移除。

本政策的变更

我们可能会不时更新本政策。变更会连同更新日期发布在本页面。变更后继续使用本应用，即视为接受修订后的政策。
